# Contributing to AlgoArena

Thanks for wanting to contribute! AlgoArena is community-driven and every contribution helps interview candidates worldwide.

## Ways to Contribute

### 1. Add New Problems

The best way to contribute is by adding problems to upcoming weeks. Each problem should include:

- **Title** and **difficulty** (easy / medium / hard)
- **Company tags** — which companies have asked this problem
- **Source links** — LeetCode, GeeksforGeeks, HackerRank URLs
- **Clear description** with input/output examples
- **Constraints**
- **4 Progressive Hints** — ordered from gentle nudge to near-solution:
  1. Hint 1: High-level thinking direction
  2. Hint 2: The key insight or data structure
  3. Hint 3: Step-by-step approach outline
  4. Hint 4: The greedy/DP property or proof intuition
- **Solution** with:
  - Approach name (e.g., "Greedy — Sort by Finish Time")
  - Plain-English explanation
  - Time and space complexity
  - Clean Python code

### 2. Improve Existing Content

- Fix typos, grammar, or formatting issues
- Add missing edge cases to examples
- Improve hint quality — make them more progressive
- Add alternative solutions
- Add company tags you know about

### 3. UI/UX Improvements

- Better responsiveness on mobile
- Accessibility improvements
- Performance optimizations
- New features (search, bookmarks, notes)

## How to Submit

1. Fork the repository
2. Create a branch: `git checkout -b add/week2-two-pointers`
3. Make your changes
4. Test locally by opening `index.html` in your browser
5. Submit a Pull Request with a clear description

## Code Style

- Problems are defined as JavaScript objects in `index.html`
- Follow the existing data structure format
- Use Python for solution code (most interview-friendly)
- Keep explanations concise but complete
