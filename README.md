## What is AlgoArena?

AlgoArena is a **free, open-source DSA practice portal** designed for engineers preparing for interviews at top companies like Goldman Sachs, Amazon, Google, Meta, PayU, and more.

Every week, a new topic drops with **hand-picked problems**, **progressive hints** (so you can try solving before peeking), **company tags** showing where each problem has appeared, and **clean, explained solutions** in Python.

### Why AlgoArena?

- **Progressive Hints** — Don't just jump to the solution. Each problem has 4 hints that guide you step by step toward the approach. Reveal one at a time.
- **Company Tags** — Know exactly which companies ask which problems. Filter your prep by target company.
- **Weekly Curriculum** — 12-week structured roadmap from Greedy Algorithms to System Design patterns. New problems every Wednesday.
- **Track Your Progress** — Mark problems as solved. Your progress persists across sessions.
- **Beautiful Dashboard** — Not another boring problem list. A proper, polished UI you'll want to keep open.
- **100% Free & Open Source** — No paywalls, no premium tiers, no ads. Built for the community.

## 🤝 Contributing

AlgoArena is community-driven and contributions are welcome!

### How to contribute:

1. **Add problems** — Submit a PR adding new problems to an existing or upcoming week
2. **Improve explanations** — Make hints clearer, add edge cases, improve solutions
3. **Add company tags** — Know which company asked a problem? Add the tag
4. **Fix bugs** — Found a typo or UI issue? Fix it
5. **Suggest topics** — Open an issue with topic ideas for future weeks

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.

### Problem format:

Each problem needs:
- Clear description with examples
- Constraints
- 4 progressive hints (easy → approach → implementation → insight)
- Clean solution with approach name, explanation, complexity, and code
